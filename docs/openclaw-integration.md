# OpenClaw Integration

ระบบนี้รองรับการรับข้อมูลจาก OpenClaw ผ่าน REST API โดยใช้ workspace API key

## 1) สร้าง API Key

ไปที่ `Settings > OpenClaw/API` แล้วสร้าง key

- key แสดงครั้งเดียว
- รูปแบบ `ck_<prefix>_<secret>`
- scope เริ่มต้น `ingest:write`

## 2) Health check

```bash
curl "$SITE_URL/api/ingest/health" \
  -H "Authorization: Bearer <YOUR_KEY>"
```

## 3) ส่ง brief เข้า Content Planner

```bash
curl -X POST "$SITE_URL/api/ingest/briefs" \
  -H "Authorization: Bearer <YOUR_KEY>" \
  -H "content-type: application/json" \
  -d '{
    "workspaceId":"<workspace_uuid>",
    "source":"openclaw",
    "brief":{
      "topic":"Promo campaign Q3",
      "angle":"Value-first messaging",
      "targetAudience":"SME founders",
      "owner":"OpenClaw",
      "contentType":"promotional",
      "format":"carousel",
      "platforms":["instagram","facebook"],
      "strategicNotes":"Generated by OpenClaw automation"
    }
  }'
```

## 4) สิ่งที่ระบบบันทึก

- `content_items` (สร้างบรีฟใหม่)
- `ingest_events` (audit log ว่ารับข้อมูลสำเร็จ/ล้มเหลว)
- `workspace_api_keys.last_used_at`
